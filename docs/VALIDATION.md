# 工作台与算法验证

验证更新：2026-10-09（Asia/Shanghai）。环境：Windows、Node.js 22.23.2、npm 11.6.0、Microsoft Edge（Chromium）。当前工作台采用单一的 0–25 色色板，新增、补齐和随机替换使用同一逐色生长流程。

## 2026-10-09：单主色固定半径偏差

截图中的 `#7A5607` 在初版 v3 中会生成近似固定彩度的圆弧。单根的唯一参考 C 被逐点线性惩罚，使明度和色相承担几乎全部变化。修正仅将单根评分改为软彩度容忍带；原有转换、候选采样、量化审计、硬边界与多根评分保留。

同一组输入、种子与约束分别运行修正前后版本。5 个单根（`#7A5607`、`#7A6068`、`#66A08F`、`#9090AB`、`#F39E9D`）各 3 个种子，再加森林、陶土各 3 个多根对照，两轮均为 21/21 完成。以下是截图主色的三个种子范围，统计均从最终 HEX 重算：

| 指标 | 修正前 | 修正后 |
| --- | ---: | ---: |
| 彩度标准差 | 0.00062–0.00126 | 0.00830–0.00865 |
| 彩度 P10–P90 跨度 | 0.00144–0.00260 | 0.02278–0.02342 |
| 可用彩度区间的 P10–P90 覆盖率 | 3.8%–6.8% | 59.5%–61.2% |

修正后该主色的最近邻色差中位数为 2.791–2.797，三个结果的 MST 最大步长均不超过 2.997，保留了近邻衔接。森林、陶土 6 个对照的完整生成结果逐项一致，包含色码、生成关系、审计与搜索统计。其他 4 个单根的彩度 P10–P90 跨度为 0.01363–0.02076，均守住硬彩度范围。边界会造成不对称：接近下界的 `#7A6068` 的彩度中位数上移 0.00629–0.01044；截图主色则下移 0.00308–0.00664。因此这里只证明径向厚度得到改善，不声称各方向概率完全对称或任意起点都能成功。

- `npm test`：**53 项通过，0 项失败**。新增径向覆盖 / 偏移 / 贴边检查，单根 24 次新增与一次补全同序列，显式窄彩度域依然可生成并严格守界。
- `npm run build`：TypeScript、Worker 与页面生产构建通过。
- 开发浏览器实际新增并编辑为 `#7A5607` 后生成 25 色，P10–P90 跨度为 0.02291，标准差为 0.00842，硬规则全部通过。排序后原色保留，上方选中同步到两图。该交互包含手动编辑，因此生成节点出生编号与纯输入实验不同，数值分别记录。
- 生产页面重复相同操作，25 个 HEX 与开发页面逐项相同，两图联动正常，无运行时错误。回放为 `output/playwright/radial-growth.js`、`radial-production.js`；截图 `radial-growth-after.png` 已目视检查。
