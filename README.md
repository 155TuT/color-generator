# 色序 · Course Color Studio

色序是一款在浏览器中运行的 0–25 色配色工具。从当前颜色出发，以小步长寻找相邻色系：颜色相距较远时补足过渡，局部接近时探索新的层次。顶部设置全局规则，左侧分析和编辑当前颜色，右侧管理色板并展示分布。

项目使用 React、TypeScript 和 Vite。计算、JSON 导入与文件导出都在本地浏览器完成，无需后端。每次打开页面从空色板开始；项目与操作历史仅存在于当前会话，不使用浏览器自动缓存。需要继续编辑时，保存 JSON 并在下次导入。

## 启动与构建

需要 Node.js 20.19 及以上的 20.x 版本，或 Node.js 22.12 及以上版本。使用 npm 安装和运行：

```powershell
npm install
npm run dev
```

打开终端显示的地址，通常为 `http://127.0.0.1:5173/`。已有依赖时直接执行 `npm run dev`；需要按锁文件安装时使用 `npm ci`。

```powershell
npm run build
npm run preview
```

`build` 执行 TypeScript 编译检查、生成静态站点并复制文档与许可文件。部署完整 `dist/` 即可；工作台在站点根路径，文档目录在 `docs/index.html`。`preview` 用于在本地打开构建结果。

## 从颜色到色板

1. 点击色板末尾的虚线加号卡，生成下一色。空色板的随机首色默认在明度 L `0.50–0.82` 和硬彩度范围内抽取，并满足文字对比。要指定颜色，在左侧编辑该色的 HEX。
2. 在左侧地图粗调色相与彩度，再用 L → h → C 控件微调。HEX 接受三位或六位写法；所有指标都按最终六位 sRGB HEX计算。
3. 在顶部设置文字颜色、最低文字对比、色差下限、底色对比上限和生成范围。右侧圆圈叹号提供悬停、键盘聚焦与点击说明。高级参数始终展开；数字输入框按内容扩宽，窄屏按组换行。
4. 点击“生成”，保留当前所有 HEX，沿同一逐色流程补到 25 色，并自动排序。选择集合不改变补全输入。生成中可点击原位的“取消生成”；计算失败或取消时保留操作前的色板。

满 25 色后隐藏加号卡。每次新增和完整补全共享同一步骤；显示排序与生成出生顺序分开维护。同一算法下，种子、规则、范围和生成记录一致时，分步新增与直接补全沿用相同的后续序列。种子由内部维护，保存在 JSON 中。

## 选择、编辑与整套操作

| 操作 | 作用 |
| --- | --- |
| 点击色块 / Shift 点击 | 切换多选或连续选择，可选任意数量。 |
| 点击色码 | 切换左侧编辑对象，不改变多选集合。 |
| 全选 / 取消选择 | 只管理选择状态。 |
| 随机 | 替换选中色，保持当前数量；部分选择保留未选 HEX 与槽位，在当前范围内抽取；全选则从首色重新生长。 |
| 删除 | 删除所有选中色，剩余颜色可继续生成。 |
| 排序 | 仅调整显示顺序，选中状态和编辑对象跟随颜色移动；已符合顺序时显示“已排序”。 |
| 生成 | 将全部现存颜色作为固定输入，补齐到 25 色并排序。 |

全选随机时，自动范围从新首色建立，固定的自定义范围继续保留。随机会在内部更换种子；新色排除本次替换前的所有 HEX。部分替换不额外排序。

编辑颜色与修改规则都会更新当前指标。手动颜色可以暂时不满足规则，以便逐项调整；继续生成前，需要先解决固定颜色与规则之间的冲突。排序不会改变颜色或解决规则冲突。

`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；macOS 可使用 Command。最多保存 100 步已提交状态，连续拖动合并为一步。纯选择和编辑焦点切换不单独占用历史，输入框内保留原生文本撤销。

## 规则与范围

| 参数 | 初始值 | 含义 |
| --- | --- | --- |
| 文字颜色 | `#FFFFFF` | 所有色块上使用的固定文字色。 |
| 最低文字对比 | `1.8` | 文字与每个底色的 WCAG 对比比值下界。滑杆的 `1.8` 和 `4.5` 刻度可点击。 |
| 色差下限 | `1.4` | 任意两色的 `100 × OKLab 欧氏距离` 下界，避免近乎重合。 |
| 底色对比上限 | `3` | 任意两种底色的 WCAG 比值上界，限制整套深浅跨度。 |
| 硬彩度 C | `0.03–0.11` | 下限避开黑白灰轴，上限限制鲜艳程度。 |
| 默认随机明度 L | `0.50–0.82` | 限制空白自动色板首色及其后续生长的明暗范围。 |

默认文字对比 `1.8:1` 用于浅色配色探索，低于 WCAG AA 常规正文的 `4.5:1`。需要相应正文对比时，选择 `4.5` 并结合实际字体、背景与布局使用。规则通过仅表示符合当前参数。

生成范围由 L、h、C 三组边界组成。自动范围从起点建立，同次生长保持稳定；手动编辑、添加或删除颜色后按现存颜色重新建立。直接修改边界会固定整组范围，点击重置恢复自动范围。L、C 下界不得大于上界；色相沿递增方向取弧，`330° → 45°` 跨过 0°，`0° → 360°` 表示完整圆周。

设备色域、生成范围和硬规则分别生效。扩大彩度生成范围不会解除硬彩度上限，降低彩度也不能替代明度或文字对比限制。显式自定义范围可以探索默认明度带之外的颜色，手动输入与导入保留原色码。

## 地图与分布

左侧地图展示当前明度 L 的 OKLCh 切片。绕中心改变色相，离中心越远彩度越高；明度由下方控件调整。地图支持缩放、复位、展开和悬停详情。

- sRGB 边界决定能否转换为当前输出的 HEX；超出该边界的点不能应用。
- Display P3 边界仅作范围参考，超出 sRGB 的部分以灰色展示。
- 生成范围和硬彩度内外圈独立显示；斜线提示当前规则不允许的区域。
- 拖动时预览，松开后应用；可用左右键调色相、上下键调彩度，Shift 增大步幅，Enter 应用，Escape 取消。

下方的方向候选每次提供一个小变化：明度 `±0.04`、彩度 `±0.015`、色相 `±15°`，并显示对规则的影响。地图与候选允许编辑出临时冲突，便于继续修正。

色板下方直接展开 a/b 和 h/L 两张分布图。选中色在两图同步标记；当前编辑色的详情显示 HEX、L/h/C、文字对比与最近邻色差。悬停或聚焦其他点可临时比较，点击图点会切换编辑对象。

最近邻中位数和 P90 描述局部密度；最小生成树的最大连边描述连接整套色板所需的最大一步；全部颜色对的分位数描述整体跨度。连线按三维 OKLab 距离构建，二维投影线长不能直接当作实际色差。空色板不显示分析，单色的颜色对指标显示“—”。

## 导入与保存

点击“导入 JSON”恢复颜色、顺序、规则、有效范围、种子和生成记录。导入接受最多 1 MB、0–25 色的 `version: 1` 文件；结构错误时保留当前工作台，有效颜色与规则冲突时允许导入后编辑。文件内附带的指标会由实际 HEX 重新计算。

点击“保存色板”设置名称、格式与保存位置，支持 1–25 色：

| 格式 | 内容 |
| --- | --- |
| JSON | 可再次导入的完整项目与当前指标。 |
| SVG | 可独立编辑的色块和文字。 |
| PNG | 用于查看或分享的图像。 |

“浏览器下载”交由浏览器处理。“自选文件夹”在支持 File System Access API 的 Chrome / Edge 中选择目录，保存前识别同名文件并显示“替换保存”。写入成功后才更新名称并关闭对话框；失败时保留当前项目与错误信息。目录句柄仅在本页会话内持有，刷新后需重新选择；不支持该 API 时仍可普通下载。

两套固定示例“水雾森林”和“暮山陶土”以相同 JSON 格式随站点提供，可从[算法文档的示例文件](docs/ALGORITHM.md#示例文件)下载，再导入查看、编辑与继续生成。示例不会自动加载，也不作为隐藏的候选色表。
